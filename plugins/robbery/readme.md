# Robbery 插件

群聊打劫小游戏：成员互相打劫抢金币、转职加持、买装备、赌博与救济。数据按群隔离，持久化到 JSON。

## 功能特性

- **打劫**：随机挑群内其他玩家，按武力平方比算成功率；成功抢对方 20%–50% 金币
- **职业**：盗贼 / 战士 / 商人 / 刺客 / 牧师，转职消耗金币并加武力 / 金钱 / 技能
- **装备商店**：木棍、铁剑、钢刀、匕首、护甲、头盔等，加武力或减损失
- **通缉与监禁**：犯罪累积提高被卫兵抓的概率；入狱若干「回合」（再发游戏指令才扣回合）
- **随机事件**：打劫成功后约 30% 触发黑市 / 意外之财 / 洗白记录
- **赌博 / 救济 / 任务 / 排行榜**：完整休闲闭环
- **仅群聊**：私聊指令不处理；数据 `群ID → 用户ID → PlayerData`

## 快速开始

1. 构建并加载插件（见下文）
2. 在群里发送 **`我的资产`** 自动建号
3. 发送 **`打劫帮助`** 查看菜单
4. 发送 **`打劫`** 开始抢人

首次互动会为当前用户创建角色（默认金钱 / 武力见配置）；真正打劫前会尽量把群成员都初始化进数据表，保证有目标可抢。

## 命令列表

| 命令 | 说明 |
|------|------|
| `打劫帮助` | 帮助菜单 |
| `我的资产` | 金钱、武力、职业、装备、犯罪与监禁状态 |
| `打劫` | 随机打劫一名可攻击目标 |
| `排行榜` | 本群财富 Top 10 |
| `职业列表` | 查看职业与技能 |
| `转职 <职业名>` | 如 `转职 盗贼`（默认 500 金币） |
| `技能` | 查看当前职业技能 |
| `商店` | 装备商店 |
| `购买 <装备名>` | 如 `购买 铁剑` |
| `赌博 <金额>` | 约 50% 胜率，赢则翻倍（商人 +10% 胜率） |
| `任务` | 每日任务展示（有刷新间隔） |
| `救济` | 破产救济（金钱 < 100 且冷却结束） |

> 匹配为**整句精确**或**前缀**（`转职` / `购买` / `赌博`）。带多余空格的「打劫 」不会命中。

|------|----------|----------|------|
| 盗贼 | +20 | +10 | 打劫成功率 +15% |
| 战士 | +30 | +5 | 初始武力向强化 |
| 商人 | +10 | +20 | 初始金钱向强化；打劫收益 +20%；赌博胜率 +10%；被抢时损失也更多 |

## 核心规则（实现摘要）

### 成功率

\[
P \approx \frac{A^2}{A^2 + D^2} \times 0.8 + 0.1 + 职业加成 + U(0,0.2)
\]

再夹紧到 **10%–90%**。\(A/D\) 为攻防**有效武力**（基础 + 职业表加成 + 装备加成）。

### 抢到金额

目标当前金钱的 **20%–50%**（商人被抢再 ×1.2）；攻击方是商人时收益再 ×1.2。

### 失败惩罚

自身金钱的 **10%–30%** 给对方；有护甲则 ×0.7。

### 通缉

基础概率 20% + 犯罪次数 ×10%。抓到：罚金约 40% 金钱 + 监禁 3 回合；逃掉则无监禁。

### 监禁

处于 `InJail` 时，除部分查询外的行动会被拦截；每次触发游戏指令会扣 1 回合，回合归零释放。

## 配置

默认值在 `main()`：

```toml
[robbery]
data_file = "data/robbery_game.json"   # 相对插件工作目录
initial_money = 100
initial_strength = 15
job_refresh_hours = 24
welfare_amount = 50
welfare_cooldown = 24                  # 小时
change_prof_cost = 500
```

| 字段 | 说明 |
|------|------|
| `data_file` | JSON 存档路径；目录不存在时保存时会创建 |
| `initial_money` / `initial_strength` | 新玩家初始值 |
| `job_refresh_hours` | 「任务」刷新间隔 |
| `welfare_amount` / `welfare_cooldown` | 救济金额与冷却 |
| `change_prof_cost` | 转职费用 |

## 数据存储

- 路径：配置的 `data_file`（默认 `data/robbery_game.json`）
- 结构：`map[chatroomID]map[userID]*PlayerData`
- 关键时机：打劫、购买、转职、赌博、救济、任务、监禁推进等写操作后 `saveData`
- 清空进度：停插件后删 JSON 即可

`PlayerData` 主要字段：金钱、武力、犯罪次数、监禁状态、职业、装备列表、打劫统计、任务 / 救济时间戳等。

## 注意事项

1. **仅群聊**；数据按群隔离，跨群资产不共享
2. 目标池来自已初始化的玩家数据；冷群可能要先多人发「我的资产」或触发过会初始化成员的指令
3. 武力 / 金币无硬上限，长期玩数值会膨胀，属娱乐向
4. 并发用 `RWMutex` 保护；存档为整表 JSON，极端高频可考虑以后换 SQLite
5. 「任务」当前主要是展示随机文案 + 记刷新时间，并非严格任务校验系统

## 常见问题

**Q: 提示没有可打劫目标？**  
A: 群内还没有其他玩家数据。让其他人发 `我的资产`，或自己先触发会 `initializeGroupMembers` 的指令后再试。

**Q: 一直在监狱？**  
A: 每次发游戏相关指令扣 1 回合；`JailTurns` 默认 3。查 `我的资产` 看剩余回合。

**Q: 数据丢了？**  
A: 检查 `data_file` 路径是否相对 Host/插件工作目录写对；重装插件勿删 `data/`；异常退出可能丢最后一次未刷盘的操作（当前为同步写盘，概率较低）。
