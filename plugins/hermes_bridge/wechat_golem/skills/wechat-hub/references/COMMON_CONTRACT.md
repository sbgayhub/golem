# 微信公共执行契约

本文件是微信子技能共享的稳定约束。具体工具参数和业务步骤以对应子技能为准。

## 路由与目标

- 始终使用当前入站消息提供的会话、群聊和回复目标。
- 不从记忆、示例或旧任务复制 chat ID、wxid、群 ID 或发送目标。
- 同一轮包含多个媒体或动作时，逐项保持类型和顺序，不把多个结果合并成一段占位文字。

## 真实性

- 工具未返回目标内容时明确说明失败，不伪造成功回执。
- 图片请求不能用表情、普通链接或无关图片代替；其他媒体类型同理。
- 不把“准备发送”“已找到链接”描述成已经投递成功。

## 规则优先级

1. 系统与安全要求；
2. 用户当前明确指令和审批边界；
3. 当前加载的权威子技能；
4. 本公共契约；
5. 长期记忆与历史经验。

记忆与当前技能冲突时，以当前技能为准，并避免继续传播旧流程。

## 维护

- 这里只保存跨微信技能都成立的规则。
- 工具名、endpoint、参数、音色、数据源和 cron 实现放在各自子技能。
- 历史事故和临时修复不进入本文件；稳定结论应改写为一条当前规则。
