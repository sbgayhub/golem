## 打劫

- 成功率 = `(A²/(A²+D²))*0.8 + 0.1 + 职业技能 + U(0,0.2)`，夹到 10%–90%
- **新增**：目标有斗牛犬时再 ×0.85
- 抢到 = 目标金币的 20%–50%（目标是商人 ×1.2；攻击方是商人再 ×1.2）
- 失败 = 自己金币的 10%–30%（有护甲 ×0.7）赔给对方
- 通缉概率 = 0.2 + 犯罪数×0.1；被抓 = 罚 40% 金币 + 监禁 3 回合
- 成功后 30% 触发随机事件（黑市/运钞车/洗钱）

## 两处整合裁决

| 冲突 | 裁决 | 理由 |
|---|---|---|
| 两套货币（阳光 vs 金币） | **合并为 `coins`** | 否则打劫抢来的钱买不了种子，两个玩法等于两张皮 |
| 监禁只锁打劫 | **农场一起锁** | 否则打劫毫无代价，关了直接被种菜收益抵消 |
| 守卫只防偷菜 | **同时 -15% 被打劫成功率** | 让 10000 金币的斗牛犬在两个玩法里都值钱 |
| 偷菜不计犯罪 | **计 1 次犯罪** | 把两个玩法接到同一个通缉系统上 |
| 修仙与农场互不相干 | **境界给农场加经验、给武力加成** | 见下表，让两条线互相喂养 |

## 数据文件

`$HERMES_HOME/wechat_games/state.json`（`HERMES_GAMES_DATA` 可覆盖，旧变量 `HERMES_FARM_DATA` 仍兼容）

```json
{"version":3,
 "players":{"wxid_x":{ ... }},
 "worlds":{"群名":{"members":["wxid_x"],"draw_jobs":[]}}}
```

玩家数据**按 wxid 全局一份**（`players`），群只记成员名单和画图队列——换群、私聊、群改名都是同一个号。
打劫 / 偷菜 / 排行榜在 `worlds[群].members` 里选人；点名的人不在本群时按名字跨群查，查到就把对方补进本群成员。
`version:1` 是只有农场的旧档、`version:2` 是玩家挂在群下的档，加载时自动迁到 3；
同一 wxid 多群各有一份时，先扫到的那份做底，其余只补空字段（不覆盖进度、不合并冷却时间戳）。
写入是「锁文件 + 临时文件 + `os.replace`」原子替换；解析失败会把原文件改名成
`state.json.corrupt-<ts>` 再重开，不静默丢数据。
